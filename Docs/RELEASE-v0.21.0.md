# ERA: Seven Realms v0.21.0

Критическое восстановление анимаций обновлённого лучника в Windows-игре поверх последнего v0.20.

- Исправлен импортёр: editor-only PreviewAnimationClip исключались из Player. Теперь все 16 прежних движений сохранены как runtime AnimationClip, GUID и ссылки восстановлены. Исходные модель, Blender Actions и FBX не пересоздавались.
- В настоящем Windows Player проверены Idle, Walk, Run, Aim, BowDraw, BowHold, BowRelease и ShootRecovery, движения костей, стрела при натяжении, игровые снаряды и совпадение release с каждым из шести тестовых выстрелов.
- Исправлено воспроизведение release при одновременном заклинании и автовыстреле. События не создают дублирующий урон или второй projectile.
- Проверены дополнительные клипы и сохранение анимаций других персонажей. DodgeRoll/Death остаются художественными черновиками; полноценное падение при смерти по умолчанию выключено. API-клипы не объявляются новыми игровыми механиками.
- Полностью сохранены обновления Regardov из v0.20: эффекты реальных механик 129 предметов, пространственный звук, густые деревья, прозрачная вода, карта, музыка и исправленные столкновения.

[Причина и восстановление](https://github.com/Regardov/Era/blob/v0.21.0/Docs/ARCHER-RECOVERY-v0.21.md) · [Проверки всех клипов и ограничения](https://github.com/Regardov/Era/blob/v0.21.0/Docs/VALIDATION-v0.21.md).

Windows x64: скачайте **Era-Windows.zip** в Assets этого релиза, распакуйте архив **целиком**, запустите **Era.exe**. Нужны Era_Data, UnityPlayer.dll и остальные файлы рядом. Установка Unity не требуется. Для кооператива используйте одинаковую v0.21 у всех игроков. Файл `.sha256` позволяет проверить архив. ZIP содержит готовую игру, не исходники.

Unity 2023.1.22f1; Editor-проверки и Windows Build прошли. Все файлы ZIP сравниваются по SHA256 с протестированной сборкой. Автоматический runtime-тест не заменяет длительный ручной playtest или проверку LAN между разными физическими ПК.
