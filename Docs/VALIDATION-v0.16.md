# Проверка ERA v0.16 — 24 октября 2026

Unity 2023.1.22f1, приложение 0.16.0, сетевой протокол 14. Исходники персонажей созданы установленным Blender 5.2.3 LTS; мастерская открыта и сохранена в его графическом интерфейсе.

| Проверка финальной сборки | Результат |
|---|---|
| `Tools/Build.ps1` | PASS: `ERA_CHECKS_OK 1831 assertions`, `ERA_BUILD_OK 400837669 bytes` |
| `Tools/Test-Characters.ps1` | PASS: 7 моделей, один skinned renderer на модель, сохранённые клипы, присед |
| `Tools/Test-Art.ps1` | PASS: модели, святилище, присед, дополнительный прыжок, описания, кристаллы |
| `Tools/Test-Solo.ps1` | PASS: пауза и продолжение, характеристики, редкости, подбор предметов |
| `Tools/Test-Campaign.ps1` | PASS: 7 миров, 7 боссов, 6 порталов, сохранение билда, прыжок, трава, Люмен |
| `Tools/Test-Update.ps1` | PASS: орды, статуя, 5 элитных стражей, бесплатный сундук, 72 ресурса, отбрасывание, модели, музыка |
| `Tools/Test-Coop.ps1 -ThreeProcesses -Headless` | PASS: хост и два гостя, у всех `ok=true`, 3 игрока, пять аур, два оружия, сложность ×4 |

Новые редакторские проверки загружают семь настоящих игровых префабов. Они проверяют SHA256 исходных данных, палитру каждой вершины, бюджет полигонов, непрерывность шеи, веса костей и границы мешей. Для каждой модели семплируются Idle, Running_A, Jump_Idle, удар и стрельба; BakeMesh проверяет конечные координаты без разлетающихся вершин. Для пяти человеческих вариантов дополнительно проверена высота нижней стопы после коррекции позы. Эти проверки добавили 138 утверждений к предыдущим 1693.

В Blender просмотрены превью спереди, сбоку и сзади. В готовой игре просмотрены семь одиночных кадров, общий бег и присед трёх героев. При итерациях исправлены длинная шея, положение плеч и обуви, чрезмерно светлая палитра и наклон сапог в приседе. Игровой экспорт исключает демонстрационный лук из Blender, чтобы он не дублировал создаваемое игрой оружие.

Исходник содержит отдельные именованные детали, материалы и арматуры; FBX экспортирован с весами без запекания новых анимаций. Игровые клипы остаются в Unity. SHA256 семи экспортов записаны в `ArtSource/Characters/character-manifest.json`.

Сетевой прогон сначала обнаружил ошибку автоматического ввода: повторение индекса аксессуара каждый кадр успевало выбирать ауру 0 до следующего снимка сервера. В сохранённом состоянии были ранги `24,1,1,0,0,0,0,0`. Исправлен диагностический сценарий: один выбор на предложение, ожидание подтверждённой смены уровня/шага, сначала новые типы аур. После пересборки все три процесса прошли проверку пяти типов. Игровой протокол и правила выбора не менялись; прочие сценарии относятся к тем же игровым моделям и механикам.

## Границы проверки

Визуальная проверка покрывает перечисленные ракурсы и позы. Все промежуточные кадры каждой атаки, пересечения всех слоёв одежды во всех сочетаниях анимаций и длительный ручной забег отдельно не проверялись. У одежды нет физической симуляции ткани; она следует весам скелета. Проверки не являются замером производительности обычного режима.

Три сетевых процесса работали на одном ПК через `127.0.0.1`, без графики. Подключение между физическими компьютерами, LAN/VPN и правила Windows Firewall отдельно не проверялись.

Unity сохранила успешную сборку, затем задержалась при выходе; Build.ps1 закрыл только свой процесс после подтверждения маркеров успешной проверки и сборки.
