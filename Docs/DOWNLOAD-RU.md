# Как скачать и запустить ERA

Игра и исходники доступны всем. Для скачивания не нужны регистрация в GitHub или приглашение.

1. Откройте [последний релиз игры](https://github.com/Regardov/Era/releases/latest).
2. В разделе **Assets** скачайте **Era-Windows.zip**. Архивы **Source code** предназначены для разработки; готовой игры в них нет.
3. Нажмите на скачанный ZIP правой кнопкой → **Извлечь всё**. Можно распаковать, например, в `C:\Games\Era`.
4. В распакованной папке запустите **Era.exe**. Unity устанавливать не нужно. Рядом должны оставаться **Era_Data**, **UnityPlayer.dll**, **MonoBleedingEdge** и остальные файлы архива.
5. Для одиночной игры выберите **Играть одному**, героя и реликвию. Подробное управление — в [PLAY-RU.md](PLAY-RU.md), также вложенном в архив.

## Кооператив для 2–3 игроков

Все скачивают один и тот же релиз. Подключитесь к общей локальной сети или VPN. Один игрок создаёт лобби, остальные выбирают подключение и вводят IP хоста. Порт — **TCP 7777**. Когда все в сборе, каждый нажимает **Готов**. Разделения экрана нет.

## Обновление

Скачайте новый архив из Releases и распакуйте в отдельную папку, чтобы не смешивать файлы разных версий. Для начала нового забега запускайте Era.exe из новой папки.

## Проверка архива

Рядом с ZIP в релизе лежит **Era-Windows.zip.sha256**. При необходимости сравните указанное значение с результатом PowerShell:

```powershell
Get-FileHash -Algorithm SHA256 .\Era-Windows.zip
```

## Исходный Unity-проект

Для разработки клонируйте этот репозиторий или скачайте **Code → Download ZIP**. Откройте корень проекта через Unity Hub в **Unity 2023.1.22f1**, затем сцену **Assets/Era/Scenes/Rift.unity**. Сборка Windows: `Tools\Build.ps1`; упаковка: `Tools\Package.ps1`.
