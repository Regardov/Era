# ERA: Seven Realms v0.29.0

Иггдрасиль размещён в центре каждого из семи миров. Высота над грунтом — около 52 м, размах кроны — около 48 м при диаметре карты 600 м. Крона остаётся высоко над персонажами; дерево занимает ограниченную центральную область.

- Три уровня детализации: 105 024 / 29 394 / 8 644 треугольника в runtime-FBX. Дальние уровни переключаются по размеру дерева на экране.
- Листва непрозрачная. Её дорогие динамические тени отключены; ствол и крупные ветви сохраняют тени.
- Корни подогнаны к рельефу каждого мира и прижаты к земле снаружи ствола. Ствол — общий для хоста и клиентов статический препятствующий объём; каменный круг перенесён рядом, на 24 м южнее центра.
- Windows ZIP содержит готовую игру, инструкции и необходимые лицензии. Библиотека создания персонажей, Blender/Python-исходники, история вариантов и большие отчёты/рендеры не включаются в Player или игровой ZIP.
- Сохранены изменения v0.27/v0.28: четыре слота бижутерии, последние клипы Люмена V12, свободное движение рук, золотая аура и исправления текста интерфейса.

Распакуйте `Era-Windows.zip` целиком и запустите `Era.exe`. `Era_Data`, `MonoBleedingEdge` и `UnityPlayer.dll` должны остаться рядом с EXE.

Проверки и измеренные результаты публикуются в `Docs/VALIDATION-v0.29.md`. Показатель FPS относится к конкретному тестовому запуску, а не гарантии для всех компьютеров. Под кроной при взгляде вверх листва закономерно перекрывает часть неба; проверяется отсутствие сплошного перекрытия в контрольных игровых ракурсах.
