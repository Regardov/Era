# ERA v0.14.0 — рост сложности и быстрый сбор золота

- У необычных предметов процентные бонусы выше 10% уменьшены вдвое. Примеры: Острый клинок +15% → +7,5%, Песочные часы +11% → +5,5%, Малое зелье +18% → +9%, Точный прицел +30% → +15%, Магнит +50% → +25%. То же правило применяется к необычным аксессуарам характеристик. Бонусы ровно 10% и ниже, а также плоские прибавки ХП/щита/дальности остаются прежними. Обновлены описания и дробные значения процентов.
- **«Вампирский клык» удалён** из эффектов, выпадения и каталога. Теперь в игре **129 предметов**. Остальные иконки исходного атласа сохранили соответствие предметам. Вампиризм остаётся доступен через аксессуар «Кровавый рубин» и «Кровавое стекло».
- **Максимальные ОЗ мобов и боссов возрастают ×1,5 при каждом переходе в следующий мир**: множители 1 → 1,5 → 2,25 → 3,375 → 5,0625 → 7,59375 → 11,390625. Сохраняются прежние множители волны и числа игроков. Уровень персонажей сам по себе не усиливает мобов.
- **Цены сундуков сохраняют накопленный рост между мирами**. Формула ceil(предыдущая цена ×5/3) использует общее число открытий команды за весь забег; новый мир не обнуляет наценку. 240 сундуков на мир сохранены.
- Золото за убийство и золотую мини-видеокарту **сразу зачисляется в общий кошелёк**, независимо от расстояния. Монетки больше не надо подбирать. Эффекты Короны жадности, Фитиля скряги, Алхимического двигателя и других предметов при получении золота продолжают работать. Кристаллы опыта остаются на земле.
- Прицел полностью убран из игрового HUD.
- Полоса босса показывает **текущие / максимальные ОЗ**. Добавлена подпись иммунитета. Боссы не получают отрицательные статусы, заморозку, замедление, оглушение или стягивание и продолжают свои атаки под ударами. Прямой урон оружия, способностей и взрывов по-прежнему действует.

Windows, Unity 2023.1.22f1, приложение **0.14.0**, сетевой протокол **13**. Всем игрокам кооператива нужна одинаковая новая сборка.
