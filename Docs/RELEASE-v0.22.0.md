# ERA: Seven Realms v0.22.0

Обновлённое движение лучника теперь включено в готовую Windows-игру.

- Бег задействует таз, позвоночник, грудь и плечи. Добавлены шесть направленных вариантов Walk/Run, всего 22 клипа.
- Прицеливание, натяжение и стрельба накладываются поверх locomotion; верхний слой больше не замораживает весь позвоночник и плащ. IK стабилизирует руки и сохраняет взаимное положение хвата и хвостовика.
- В поворотах корпус наклоняется и постепенно доворачивается к цели. Плащ и колчан реагируют на разгон, остановку и повороты с ограниченной инерцией.
- Сохранены модель, 54-костный Generic-риг, материалы, прежние 15 клипов, не требовавшие правки, и исправление импорта runtime AnimationClip из v0.21.
- Сохранены обновления Regardov: механики предметов, эффекты и пространственный звук, густые деревья, прозрачная вода, карта, музыка и столкновения.

[Устройство анимаций и игровые кадры](https://github.com/Regardov/Era/blob/v0.22.0/Docs/ARCHER-MOTION.md) · [Проверки сборки](https://github.com/Regardov/Era/blob/v0.22.0/Docs/VALIDATION-v0.22.md).

Известные ограничения: остаются локальные контакты рукава с капюшоном и плаща с ногой в крайних позах. DodgeRoll и полноценная Death остаются художественными черновиками; полноценное падение при смерти по умолчанию выключено. Нет вертикального aim и terrain-aware foot IK. Автоматические проверки не заменяют длительный ручной playtest.

**Windows x64:** скачайте **Era-Windows.zip** из Assets релиза, распакуйте **целиком**, запустите **Era.exe**. Сохраните рядом Era_Data, UnityPlayer.dll, MonoBleedingEdge и остальные файлы. Unity устанавливать не нужно. Для кооператива используйте одну и ту же **v0.22** на всех компьютерах. Файл **Era-Windows.zip.sha256** содержит контрольную сумму. Архив содержит готовую игру.

Unity **2023.1.22f1**. Проектные проверки, Windows Build и игровые сценарии лучника проверены перед публикацией; все файлы архива сравниваются с протестированной сборкой по SHA256.
