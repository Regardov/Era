Новые редакторские сценарии проверяют реальные количества спавнов для 1 / 2 / 3 игроков, коэффициенты ОЗ и урона обычного врага и босса, урон особой атаки босса. После победы над боссом живые враги сохраняются, а частота спавна дополнительно удваивается. На 10-й и 20-й секундах проверены множители 1,1 и 1,21, сохранение доли оставшихся ОЗ и наследование усиления новыми мобами. Проверены пересчёт после отключения игрока, сериализация данных для клиентов и сброс усиления через портал с сохранением обычного роста между мирами.

Все четыре исходных PNG скопированы без изменения; SHA256 каждой копии совпадает с вложением. Для 129 предметов проверены наличие текстуры, спрайта и границы области; 120 предоставленных рисунков имеют отдельные ячейки. Девять предметов, которых нет на изображениях, используют прежние иконки. Просмотрены четыре страницы каталога и кадры окружения, босса и волны после его смерти.

Первый прогон обнаружил превышение бюджета рендереров после добавления кустов: 871 при ограничении 800. Укрупнение групп растительности и камней снизило итоговое число до 714. На визуальной проверке исправлено перекрытие поднятой полосы босса слотами оружия. Неиспользуемые библиотеки промежуточных запеканий перенесены в игнорируемые Artifacts; внешние GUID итоговой сцены разрешаются. `git diff --check` проходит.

## Границы

Три сетевых процесса работали на одном ПК через 127.0.0.1. Реальная LAN/VPN, Windows Firewall и длительный ручной баланс всех билдов отдельно не проверялись. Первый сетевой запуск внутри песочницы завершил гостевые процессы аварийно; повторный запуск вне песочницы прошёл у всех участников. Окружение и HUD проверены с графикой; сетевой тест запускался без графики. Диагностика ограничена 20 FPS и не является замером производительности обычного режима.

Unity успешно сохранила билд, но зависла при завершении; Build.ps1 закрыл только свой процесс после подтверждённых маркеров успешной сборки и выхода.
