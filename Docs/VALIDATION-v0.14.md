## Новые сценарии

Проверены точные новые значения 16 необычных предметов, сохранение бонусов ровно 10% и плоских прибавок, дробные 7,5% у необычного аксессуара и неизменность редкого аксессуара. Каталог и enum содержат 129 предметов без «Вампирского клыка»; проверены координаты оставшихся иконок атласа и иконки новых предметов после сдвига ID.

Для каждого из семи миров проверены реальные максимальные ОЗ обычного моба и босса по формуле 1,5^(номер мира−1). При переходе через портал все сундуки наследуют полное число открытий забега в расчёте цены.

Удалённое убийство сразу зачисляет золото с бонусом владельца, золотой GPU платит один раз без монет на полу, устаревшие монетки автоматически конвертируются с любого расстояния. Сохранены срабатывания Фитиля скряги и Алхимического двигателя при получении золота. Дробные множители опыта и золота продолжают накапливать остаток.

Песочные часы и Хроносфера замораживают обычных врагов, но не босса. Босс не принимает горение, яд, кровотечение, охлаждение, метки и заморозку от сочетания предметов. Старые статусы очищаются, воронка не сдвигает босса, атаки продолжаются. Прямые удары продолжают снимать ОЗ. Визуальная реакция босса не прерывает анимацию атаки.

## Границы

Сетевой тест использует один ПК и адрес 127.0.0.1. Реальная LAN/VPN, Windows Firewall и длительный ручной баланс всех билдов требуют отдельной проверки. Диагностические окна ограничены 20 FPS; это не замер обычного режима. Unity на этом ПК может зависнуть при выходе после успешного сохранения билда; Build.ps1 закрывает только свой процесс после подтверждённых маркеров завершения.
