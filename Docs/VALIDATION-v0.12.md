## Границы проверки

Кооператив проверен тремя отдельными процессами на одном ПК, через TCP 127.0.0.1:7777. Отдельные компьютеры, VPN, задержки реальной сети и Windows Firewall в этот прогон не входили. Баланс всех возможных сочетаний 130 предметов не заменяет длительный ручной плейтест.

Первый запуск Unity в песочнице остановился на локальном LicensingClient с кодом 199; сборка выполнена с доступом к установленной лицензии. Песочница также вызвала нативный сбой гостевых Mono-процессов; повторный локальный сетевой тест вне этого ограничения прошёл. Ранняя версия кооперативной диагностики снимала отчёт хоста раньше завершения выбора Люмена; финальная ждёт получения второго оружия всеми участниками. Эти проблемы не оставлены как успешные проверки.

Последняя пересборка меняла только синхронизацию окончания сетевой диагностики и её адрес 127.0.0.1; игровой код перед ней прошёл все перечисленные одиночные сценарии. После неё повторно прошли 1353 редакторские проверки и три отдельных сетевых процесса.
