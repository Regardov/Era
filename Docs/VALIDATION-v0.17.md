# Проверки ERA v0.17 · 24 октября 2026

Unity 2023.1.22f1. Текущие исходники собраны в Windows Player; `ERA_CHECKS_OK 2399 assertions`, `Build Finished, Result: Success.`, `ERA_BUILD_OK 399624109 bytes`.

Первый запуск Unity в ограниченной среде не получил доступ к лицензии; сборка повторена с локальным доступом. После успешного сохранения Player Unity остановилась на телеметрии `cdp.cloud.unity3d.com`; завершён только соответствующий фоновый batch-процесс. Сохранённая сборка проверена следующими запусками игры.

| Проверка | Результат текущей сборки |
|---|---|
| `Tools/Test-Characters.ps1` | PASS: 7 моделей, skinned meshes, клипы, присед |
| `Tools/Test-Solo.ps1` | PASS: пауза и продолжение при повышении уровня, характеристики, предметы |
| `Tools/Test-Art.ps1` | PASS: модели, святилище, присед, дополнительный прыжок, описания, кристаллы |
| `Tools/Test-Balance.ps1` | PASS: каталог, присед, щит, уклонение, подсказки, 240 сундуков |
| `Tools/Test-Update.ps1` | PASS: волны, статуя, 5 элитных врагов, бесплатный сундук, 72 ресурса, отдача, модели, музыка |
| `Tools/Test-Campaign.ps1` | PASS: 7 миров, 7 боссов, 6 порталов, прыжок, трава, модель Люмена, сохранение сборки персонажа |

Редакторские проверки включают направление сгиба обоих коленей на пяти человеческих моделях, Idle/Walking_A в трёх моментах клипа и трёх фазах приседа, опору стоп, закрытую основу волос, точные ОЗ семи боссов, пороги и остаток общего опыта, прежнюю частоту волн и орды после босса. Для 24 seed проверены случайные безопасные точки игрока и статуи, разделение минимум на 45 м, размещение трёх союзников рядом, воспроизводимость и сериализация. Проверена высота каменных площадок над землёй. Существующие проверки локального TCP с тремя участниками входят в редакторский прогон.

Просмотрены актуальные игровые кадры [Эхо](Images/character-Echo-v017.png), [присед спереди](Images/characters-crouching-v017.png), [присед сбоку](Images/characters-crouching-side-v017.png), а также Blender-превью обновлённой причёски. У стоп сохранена опора; колени направлены к лицевой стороне персонажа.

Полный ручной забег с оценкой темпа прокачки и сражением с каждым боссом до смерти не проводился: тест кампании использует диагностический урон. Сетевой забег на разных физических компьютерах в этой проверке не запускался. Для кооператива всем нужна одна версия v0.17.
