## Повторно использованные проверки неизменённых систем

При интеграции `4b84ca0` уже выполнены 16 сценариев с ограничениями 15/30/60 FPS, проверка семи моделей и приседа, 108 поз ригов с шестью видами оружия и регрессии эффектов с 90 врагами. Игровые скрипты, клипы, геометрия и контроллеры при подготовке версии 0.22 не менялись. Повышены номер версии и данные релиза/упаковки. [Подробности и исходные отчёты](ARCHER-MOTION.md).

## Архив

`Tools/Package.ps1` собирает полный Windows Player в `Era-Windows.zip`, добавляет инструкции, описание v0.22 и подтверждения проверок. `Tools/Verify-Package.ps1` проверяет обязательные файлы, успешный runtime-отчёт именно версии 0.22.0 и побайтовое совпадение каждого файла архива с протестированной сборкой через SHA256. Контрольная сумма ZIP находится в отдельном `Era-Windows.zip.sha256` рядом с архивом в GitHub Release.

Запуск: распаковать весь архив в отдельную папку и открыть `Era.exe`; для кооператива на всех ПК использовать v0.22. Unity устанавливать не нужно.

## Оставшиеся ограничения

Сохраняются локальные контакты рукава с капюшоном и плаща с ногой в крайних позах; полной очистки всех смешиваний нет. DodgeRoll и полноценная Death — художественные черновики, падение при смерти по умолчанию выключено. Нет вертикального aim и terrain-aware foot IK. Длительное ручное прохождение и LAN-сеанс на разных физических компьютерах в этом релизном проходе не проверялись. [Полный перечень](ARCHER-MOTION.md#remaining-issues).
