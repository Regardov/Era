# Присланные иконки · первая десятка

В `Assets/Era/Resources/Items/v029` сохранены десять обработанных RGBA PNG на основе присланных изображений. Фон извлечён встроенным imagegen; [набор запросов](prompts.json). В исходниках уже был альфа-канал, но местами по краям оставалась почти невидимая вуаль с альфой 1/255. Unity-импорт обнуляет значения альфы до 4/255 и создаёт полностью прозрачный внешний отступ в 3 px. Игровые PNG 256 × 256 с окончательной альфой экспортируются в `Runtime`.

Точные оригиналы 1254 × 1254 сохранены в `Originals`, файлы в Downloads не изменяются. [Имена исходников и обе контрольные суммы SHA-256](manifest.json). Обработанные варианты могут немного отличаться по граням и кадрированию; тип предмета, композиция и исходный стиль сохранены.

`IconLibrary.ItemResourcePath` использует новые файлы для этих ID во всех местах: каталог, инвентарь, уведомления и добыча на земле. Остальные 119 ID продолжают использовать свои изображения v0.25. Базовые SVG v0.25 остаются историческими рисунками; они не являются источниками присланных растровых иконок.

Импортёр `SuppliedItemArtwork` включает `alphaIsTransparency`, отключает сжатие и mipmaps, ограничивает игровую текстуру 256 px. `ItemArtChecks` сверяет SHA-256 выбранного обработанного PNG и проверяет прозрачные края; `Test-Update29.ps1 -Visible` показывает все десять на светлой и тёмной подложках настоящего интерфейса.
