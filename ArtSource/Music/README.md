## Послушать

`ERA-Soundtrack-Preview.ogg` содержит по десять секунд каждого трека в порядке таблицы: 0:00 — меню, 0:10 — мир 1, …, 1:10 — мир 7. Превью имеет короткие затухания между фрагментами. Полные зацикленные мастера находятся в `Assets/Era/Resources/Audio/*.ogg`.

## Повторная запись

Требуются Python с `numpy` и `soundfile`, [FluidSynth 2.6.1](https://github.com/FluidSynth/fluidsynth/releases/tag/v2.6.1) и [GeneralUser GS 2.0.3](https://www.schristiancollins.com/generaluser.php). Эти инструменты нужны только для изменения/перезаписи музыки; сборка Unity использует уже готовые Ogg-файлы.

```powershell
python -m pip install numpy soundfile
python ArtSource/Music/compose_soundtrack.py --fluidsynth "C:/path/to/fluidsynth.exe" --soundfont "C:/path/to/GeneralUser-GS.sf2"
```

Параметр `--only 0 3` перезапишет только меню и третий мир. Временные записи трёх проходов сохраняются в `Artifacts/MusicRender`; средний проход используется как петля с уже установившимися хвостами инструментов и реверберации. Первые 60 мс соединяются с продолжением следующего прохода, затем применяется удаление дозвуковой составляющей и мягкое ограничение пиков. Ogg записывается блоками, чтобы не переполнять нативный стек кодека Windows.

`soundtrack.json` содержит точную длительность, темп, инструменты, SHA256 каждого Ogg, измеренные пиковый/RMS-уровни и перепад на границе петли после декодирования. Во всех восьми файлах — stereo 44,1 кГц; проверяются перегруз, длительные провалы сигнала и граница петли. RMS используется для выравнивания уровня, это не измерение LUFS.
