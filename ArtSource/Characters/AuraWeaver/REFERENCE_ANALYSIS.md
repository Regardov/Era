# Aura Weaver — анализ референса и измерения

Референс пользователя — художественная трёхракурсная иллюстрация, не ортографический технический чертёж. В переднем виде руки согнуты для магии; боковой и задний виды отличаются позой. Яркая руна в центре — будущий VFX, в модель по заданию не включена. Светлые тёплые блики не принимались за обязательные цвета материала.

## Образ и силуэт

Приоритеты: широкая угловатая шляпа с согнутым концом → капюшон и тёмные пряди у лица → короткая V-накидка → тёмный торс → узкая область пояса с подсумками → несколько расширяющихся длинных панелей → свободные колоколообразные рукава и небольшая угловатая обувь. Лицо человеческое, без маски/эльфийских ушей; орнаменты геометрические, не религиозные.

При оценке в изображении ориентировочно: поля шляпы около 0,30 H; наружная ширина одежды у плеч около 0,23–0,27 H; низ мантии около 0,30–0,34 H; пояс примерно на 0,55–0,58 H от подошв. Это оценки видимого контура с перспективой, а не измерение скрытой анатомии.

## Измеренная модель

Blender: Z вверх, −Y вперёд, метры. Величины определены по rest-геометрии, а не AABB вспомогательных костей оружия.

| Часть | Размер / определение |
|---|---|
| Высота с головным убором | 1,970 м; проектный ориентир был 1,98 м |
| Ширина полей шляпы | 0,602 м после сравнения; первоначально 0,646 м |
| Глубина шляпы | 0,564 м |
| Высота шляпы | около 0,306 м |
| Голова с маленькими человеческими ушами / ширина | 0,212 м |
| Высота head-компонента | 0,248 м; включает нос и facial-поверхности |
| Наружная ширина короткой накидки | около 0,530 м после сравнения; первоначально 0,630 м |
| Пояс / наружная ширина | 0,290 м |
| Панели мантии | от Z≈1,015 до Z≈0,125 м, отдельные front/side/back слои |
| Максимальная общая ширина | около 0,714 м за счёт свободных манжет, не ширина плеч |

54 исходные rest matrices сохранены без изменений. Пропорции костюма изменены независимо от костей: ширина мантии, рукавов, шляпы и накидки не копирует эльфийский костюм. Скрытые ноги и ботинки взяты из проверенной конструкции, внешнее тело/голова созданы заново.

## Сравнение и внесённые исправления

1. Закрыт сквозной центральный просвет: добавлена самостоятельная тёмная внутренняя одежда и узкий янтарный центральный элемент.
2. Задний шов наружных панелей перекрыт, боковые панели получили объём и соответствующую нормали толщину.
3. Затылок капюшона заострён, добавлены длинные передние отвороты с тёплой подкладкой.
4. Загиб шляпы выведен наружу конуса, поля и короткая накидка сужены по сравнению с первым blockout.
5. Связанная геометрия ладоней/пальцев заменяет отдельные накладные пальцы; манжеты имеют внутреннюю полость.
6. Для новой длины мантии созданы дополнительные FK-цепи; в Death короткая одежда лучника не переносилась вслепую.

Проверены четыре основных ракурса в Blender и Unity, отдельные Run/AuraChannel/Death/Cast/JumpStart позы. Окончательную художественную оценку не подменяют счётчик треугольников и успешный импорт. Оставшиеся различия и контакты перечислены в README и JSON.
