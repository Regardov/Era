# Люмен V12 — шаг и движение рук

Источник — сохранённая V11; Blender 5.2.3 LTS. Геометрия, rest skeleton и девять остальных Actions сохранены. Заменены только `AuraWeaver_Walk` и `AuraWeaver_Run`.

- Руки свободно двигаются в противоход ногам, локти сгибаются, кисти направлены вниз. В игре удерживаемая руна затухает при обычном движении, чтобы не перекрывать руки.
- Walk: цикл 0,8 с, опорная фаза 62%; Run: цикл 0,6 с, опорная фаза 56%. Подъём стоп, перенос ноги и движение корпуса согласованы с фазой шага. Это визуальные клипы; скорость симуляции не изменяется.
- Высота таза учитывает досягаемость опорной ноги. Проверка вычисляет положение подошв по деформированным мешам: см. `contacts.json`. Измерение в исходнике не заменяет проверку рельефа и мантии в Player.
- Сохранены 90 костей, 26 мешей и 11 клипов. Передние/задние сумки следуют тазу. `validation.json` содержит подтверждение сохранности девяти Actions и измерения маха рук.

Сборка исходника и экспорта: `blender --background --python ArtSource/Characters/AuraWeaver/ReleaseV12/animate_walk.py`. Контакт стоп: `blender --background --python ArtSource/Characters/AuraWeaver/ReleaseV12/verify_contacts.py`. Предыдущие V10/V11 и исходники лучника не перезаписываются.

В Unity расширен геометрический зазор мантии для новой амплитуды шага; порог проверки пересечений сохранён. Реальные игровые кадры и проверки: [VALIDATION-v0.28.md](../../../../Docs/VALIDATION-v0.28.md).
