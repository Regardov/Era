# Aura Weaver — отдельный подготовленный персонаж ERA

Первая версия по предоставленному трёхракурсному `Reference.png`: человек в кремово-янтарной мантии, широкополая шляпа с загнутым концом, капюшон, тёмные волосы, кожаные подсумки и перчатки. **Рун, постоянных магических дисков, религиозной символики и VFX нет.** Новый персонаж не заменяет лучника или Люмена и не добавлен в выбор героя.

## Файлы и просмотр

- [AuraWeaver.blend](AuraWeaver.blend) — самостоятельный редактируемый исходник, 21 меш, 86 костей, 11 Actions. Внутри есть студия и камеры. Исходник открывается в Blender 5.2.3 LTS; Timeline по умолчанию показывает Idle. Выберите Action с префиксом `AuraWeaver_` в Action Editor для другого движения.
- [AuraWeaver_Rigged.fbx](AuraWeaver_Rigged.fbx) — выбранные меши/риг и 11 запечённых takes, без студии.
- [Unity Prefab](../../../Assets/Era/Art/Characters/AuraWeaver/AuraWeaver.prefab) — `Assets/Era/Art/Characters/AuraWeaver/AuraWeaver.prefab`. Открыть в Prefab Mode; контроллер и реальные runtime `.anim` лежат рядом. Переносить вместе с `.meta` и зависимостями, а не один `.prefab`.
- [Front](Previews/AuraWeaver-front.png), [Side](Previews/AuraWeaver-side.png), [Back](Previews/AuraWeaver-back.png), [3/4](Previews/AuraWeaver-perspective.png), [AuraChannel](Previews/Pose-AuraChannel.png).
- [Фактический вид Unity](Previews/Unity-perspective.png) и [поза рук в Unity](Previews/Unity-channel.png). Освещение/тональное преобразование Unity отличаются от AgX в Blender.
- `AuraWeaver_Blockout.blend`, `AuraWeaver_Blockout_MCP.blend` — крупные формы и отдельный промежуточный проход через Blender MCP.

## Что переиспользовано

От эталонного лучника: **54 исходные кости с неизменными именами, родителями и rest matrices**, десять Actions как основа отдельных копий, отредактированная геометрия ботинок и скрытых ног из Character Factory, способы loft-построения, линейная запись палитры, настройки FBX. Ошибка rest matrices исходной схемы: **0**.

Лицо, человеческие уши, волосы, шляпа, капюшон, накидка, рукава, пояс, подсумки, вся длинная мантия и цельные перчатки построены для нового референса. Эльфийские уши, зелёный костюм, лук и колчан не копировались. В скелете сохранены пустые extension bones лучника ради Generic paths; мешей оружия нет.

Исходный `Archer_Animated.blend` имеет прежний SHA256 `121d810b74dc150a88ee1ed213d76580d96ad479185cb4fdf87adf3a713236fd`. Его .anim, контроллер и игровые Prefab не редактировались.

## Риг, меши и веса

- **86 костей:** совместимые 54 + 20 суставов пальцев + 12 костей длинных панелей мантии. Это расширенный **Generic**; Unity Humanoid Avatar не создавался и не сертифицирован.
- Объект Armature называется `Archer_Rig` для сохранения путей `Archer_Rig/Root/...`. Это техническое имя, а не геометрия лучника.
- 83 исходных детали объединены в **21 логический меш**: голова, волосы, шляпа, капюшон, шарф, накидка, торс, шея, наружная/внутренняя мантия, пояс, две группы подсумков, два рукава, две перчатки, две ноги и два ботинка.
- Связанные геометрические острова не сваривались автоматически. Одежда сохраняет отдельные слои; исходные части после объединения доступны через группы `PART_*`. Эти группы не являются deform bones.
- Обе перчатки: **по одному связанному острову**, 0 открытых/неманифолдных рёбер, 0 нулевых граней. Ладонь, четыре пальца и большой палец имеют общие граничные вершины.
- У всех вершин нормализованные веса, нет невзвешенных вершин; максимум **4** deform-влияния. Flat Shading, без Subdivision/voxel remesh. **3 360 треугольников**.

## Анимации

| Клип | Источник и назначение |
|---|---|
| Idle / Walk / Run | Копии движений лучника, новые FK-ключи мантии/пальцев и контроль пола для этого костюма |
| JumpStart / Airborne / Fall / Land | Существующие воздушные движения с новой одеждой; физическую траекторию должен задавать игровой код |
| Cast / Hit | Копии существующих действий; события урона/аур не добавлялись |
| Death | Адаптированная копия: панели направляются к ногам, добавлена вертикальная компенсация контакта нового костюма с полом |
| AuraChannel | Новая двухручная демонстрационная поза поверх дыхания Idle, без символа и VFX |

Каждый клип начинается `AuraWeaver_`. FBX содержит 11 takes; Unity создал 11 самостоятельных runtime AnimationClip, не editor-only PreviewAnimationClip. Все 11 проверены выборкой деформированных мешей и вычислением собственного Animator Controller. Десять соответствующих оригинальных .anim лучника также проверены на наличие всех transform paths. Дополнительные пальцы/мантия требуют новых адаптированных копий для полноценного движения — старые клипы сами их не анимируют.

При импорте сокращаются только постоянные каналы с плоскими касательными; движущиеся кривые сохраняют запечённую частоту. Оригинальные клипы лучника не сжимаются и не перезаписываются.

В Blender проверено **55 поз** (5 времён на клип), в Unity — такие же выборки конечной геометрии. Это не непрерывная сертификация всех переходов или игра нового героя в забеге.

## Unity и дальнейшее подключение

Импортёр: `ERA → Aura Weaver → Import and validate separate prefab`, Unity **2023.1.22f1**. Визуальная ветка использует тот же коэффициент `2.23/1.8`, что и лучник: тело согласовано по масштабу, высота со шляпой примерно **2,44 м**. Root Motion выключен. Корневые CapsuleCollider и kinematic Rigidbody — подготовка, не новый контроллер движения.

Параметры Animator: `Speed` (м/с), `LocomotionRate` (по умолчанию 1), `IsGrounded`, `VerticalSpeed`, триггеры `Jump`, `Cast`, `Hit`, `Death`, bool `AuraChannel`. Основной слой смешивает Idle/Walk/Run; есть отдельные состояния воздуха и действий. Для независимой магии поверх бега потребуется осмысленная последующая настройка слоёв/масок, она не выдаётся за сделанную.

**Для появления в меню/забеге нужна отдельная привязка к существующей системе Hero и игровому драйверу анимаций.** Новый класс, способности, выбор аур и механика лечения не создавались по ограничению задания. `ArcherAnimationDriver` автоматически не назначался: он требует стрельбу и экипировку лучника. Legacy-риг старого Люмена тоже не считается совместимым автоматически.

## Проверки и оставшиеся отличия

[Blender-проверка](blender-validation.json) · [Unity-проверка](unity-validation.json) · [Разбор силуэта](REFERENCE_ANALYSIS.md).

Силуэт, костюм и палитра воспроизводят основные признаки референса. Front/Side/Back/3/4 сверены; руки в Idle опущены намеренно, поза референса отдельно представлена AuraChannel. Это не пиксельная копия иллюстрации.

Остаются отличия: форма загиба шляпы и крупные складки накидки проще рисунка; глаза/волосы и локальный рисунок переходов ткани не совпадают точно. Death всё ещё требует художественной чистки ткани в промежуточных позах: автоматическая проверка отмечает контакты некоторых передних панелей с ногами; они не скрыты в JSON. Пять времён не доказывают отсутствие пересечений на всём клипе. Нет симуляции ткани, выражений лица и проверки деформаций в полном игровом забеге. Новый Windows Release не создавался.

## Воспроизводимость

Запускать из checkout ERA, с установленным Blender:

```powershell
blender --background --factory-startup --python-exit-code 2 --python ArtSource/Characters/AuraWeaver/build_aura_weaver.py
blender --background ArtSource/Characters/AuraWeaver/AuraWeaver.blend --python-exit-code 2 --python ArtSource/Characters/AuraWeaver/export_validate_weaver.py
```

Первый шаг создаёт отдельный исходник из Character Factory; второй проверяет сырые компоненты, объединяет логические группы и экспортирует. Не запускать второй шаг повторно на уже объединённом файле без первого. Затем выполнить меню импортёра Unity. Все записи ограничены новым персонажем и его предпросмотрами.
