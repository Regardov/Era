# Люмен V11 — видимые кисти

Основа: сохранённая `ReleaseV10/AuraWeaver_Lumen_V10.blend`, Blender 5.2.3 LTS. Новый исходник — `AuraWeaver_Lumen_V11.blend`; экспорт — `AuraWeaver_Rigged.fbx`.

В V10 край левого рукава выступал примерно на 11,7 см за запястье, правого — на 5,4 см. Кисти оказывались внутри широких манжет. В V11 окончания обоих рукавов находятся на 1,2 см позади запястья; сужение затрагивает только нижнюю часть предплечья. Исходные ладони и пальцы сохранены. Замкнутый объёмный манжет построен продолжением проверенной границы запястья, с переходом весов между кистью и предплечьем.

Риг, rest matrices и ключи всех 11 Actions сохранены. Сравнение сохранённых V10/V11 подтвердило одинаковые SHA-256 наборов костей и анимационных кривых; значения и геометрические проверки находятся в `validation.json`. Исходные V10 и лучник не изменялись. Цвета и число мешей сохранены.

Воспроизведение: `blender --background --python ArtSource/Characters/AuraWeaver/ReleaseV11/fix_hands.py`. Пять крупных планов находятся в `Previews/`; игровые кадры и результаты проверки — в `Docs/VALIDATION-v0.27.md` после завершения проверки Player.
