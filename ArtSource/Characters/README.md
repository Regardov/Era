# Мастерская персонажей ERA · v0.19

Откройте `ERA_Character_Workshop-v19.blend` в Blender 5.2 LTS. В сцене находятся семь отдельных коллекций с редактируемыми мешами, материалами и арматурами. Имена деталей описывают их назначение. Цвета заданы материалами и гранями; внешние текстуры для этих моделей не нужны. В v0.19 добавлены изогнутые объёмные пряди, закрытая основа волос, связные рукава с плавными весами, толщина одежды, более округлые силуэты и пальцы для хвата оружия. Исходный `ERA_Character_Workshop.blend` сохранён отдельно, включая ручные правки.

`Previews/*-v19.png` содержит изображения каждой модели спереди, сбоку и сзади. Семь финальных файлов `v19/*.fbx` содержат именованные детали, арматуры и веса в позе привязки. Ранние экспорты в корне сохранены; для этой версии используйте каталог `v19`. Новых анимационных клипов в FBX нет: игровые префабы используют сохранённые клипы KayKit и их лицензию CC0. Оригинальные референсы пользователя в архив не включены.

Пять моделей уже используются в игре. `Wayfarer` и `DuskMage` находятся в `Assets/Era/Resources/Characters/Library`; это дополнительные варианты с совместимым скелетом, а не новые классы с отдельными умениями. В Blender у Искры есть демонстрационный лук; игровой меш его исключает, поскольку оружие создаёт сама игра.

## Пересоздание исходников

Из корня полного проекта ERA выполните в PowerShell (путь к Blender можно заменить):

```powershell
& 'D:\SteamLibrary\steamapps\common\Blender\blender.exe' --background --factory-startup --threads 4 --python-exit-code 3 --python ArtSource/Characters/build_characters.py
```

Команда перезаписывает сгенерированный `ERA_Character_Workshop-v19.blend`, `v19/*.fbx`, превью v19, манифест и `Assets/Era/Art/BlenderCharacters/*.era-mesh.json`. Перед повторным запуском сохраните ручные изменения под другим именем. Исходный `ERA_Character_Workshop.blend` команда не меняет. Для работы скрипта нужен полный проект с исходными Unity-префабами; отдельный архив мастерской можно открывать и редактировать без Unity.

В Unity используйте **ERA → Import Blender character workshop**, затем `Tools/Build.ps1`. Импортёр объединяет игровые детали в один SkinnedMeshRenderer на модель, переносит цвета граней, нормали и веса, создаёт сокеты ладоней и корректирующие формы пальцев/одежды, сохраняет существующие игровые компоненты и анимации. Для ручных правок `.blend` нужно также обновить экспорт JSON: сам факт сохранения `.blend` не меняет готовый игровой префаб.

`character-manifest.json` содержит число треугольников, вершин, деталей и SHA256 экспортированных игровых данных. Проверка `Tools/Test-Characters.ps1` загружает все семь префабов, снимает позы и сохраняет отчёт в `Artifacts/smoke-characters.json`.
