# Работа над ERA

- По постоянной просьбе пользователя после каждого завершённого задания на изменение проекта делайте коммит и пуш в настроенный GitHub remote текущей ветки.
- Перед коммитом выполните проверки, соответствующие изменению. Используйте уже актуальные результаты, если код после них не менялся; не пересобирайте игру ради правки документации.
- Проверяйте успешность пуша по удалённому commit SHA. Локальный коммит без успешной отправки не считайте выполненным пушем.
- Не используйте force-push, не переписывайте чужую историю и не включайте посторонние незавершённые изменения.
- Вложенный `Website` — отдельный Git-репозиторий сайта. Не добавляйте его в основной репозиторий как gitlink без настроенного submodule.
