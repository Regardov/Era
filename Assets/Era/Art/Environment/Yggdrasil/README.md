# Иггдрасиль: только игровые данные

В этой папке находятся три runtime-FBX, компактный манифест геометрии и материалы. Исходный Blender и генератор не копируются в Unity Assets.

Локальный оригинал: `C:/Users/kolon/Documents/Codex/ERA-Character-Library/Working/Yggdrasil-V1/Yggdrasil_V1.blend`.

`WorldTreeImporter` создаёт prefab `Resources/Environment/Yggdrasil`, задаёт высоту около 156 м и крону около 144 м. `WorldTreeView` размещает один экземпляр в центре активного мира и подгоняет только частные копии мешей корней к рельефу. Исходные меши и материалы сохраняются.

Исходные треугольники LOD0/1/2: 105024 / 29394 / 8644. Simplification применяется только к дальним копиям, не к локальному master. Произвольная анимация ветра пока не добавлена.
